# 宏观经济学 · 自学网站

这个文件夹是一个 **Git 仓库**（repository），里面放的是《宏观经济学》自学课程的全部内容：

| 文件 | 作用 |
| --- | --- |
| `index.html` | 课程主页，双击就能用浏览器打开 |
| `styles.css` | 页面样式（配色、排版） |
| `app.js` | 页面里的互动功能（进度、自测题等） |
| `知识点清单与PPT对照.md` | 知识点总清单 + 对应原 PPT 的页码 |

## 怎么看

- **在电脑上**：双击 `index.html`。
- **在手机上 / 任何一台电脑上**：推送到 GitHub 后开启 Pages，访问
  `https://你的用户名.github.io/仓库名/`

## 每天最常用的 4 条命令

```bash
git status                 # 看看现在有哪些改动还没存档
git add -A                 # 把所有改动放进"待存档"篮子
git commit -m "改了啥"      # 存档，写清楚这次改了什么
git push                   # 上传到 GitHub
```

## 遇到问题想退回去

```bash
git log --oneline          # 看历史存档列表（每条前面是编号）
git show <编号>             # 看某一次到底改了什么
git restore 文件名          # 把某个文件恢复到上次存档的样子
```

## 这个仓库的来历

最初是用 AI 生成的单页课程，后来搬到 Git 里管理，好处是：

- 每次改动都有记录，改坏了能退回去，不用重新生成一遍；
- 手机、平板、别的电脑都能打开同一个链接，看到的是同一个版本；
- 完全免费，静态页面不需要租服务器。
